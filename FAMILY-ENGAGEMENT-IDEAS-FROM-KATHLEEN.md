# Family Engagement Ideas — This Week / Family Hub (FROM KATHLEEN)

*Captured 2026-08-08 during the live onboarding dress rehearsal. **Backlog / product direction — do NOT implement during the current family-join roster fix.** These are to be *considered in the build roadmap* for the family-facing hub once the core flow is verified. Sequence after: (1) the affiliations read-side fix, (2) This Week schedule + roster verified end-to-end.*

## North star
Make Relevé the **go-to hub** for competition families. Convenience is the wedge: if families find it easier to keep up through Relevé than through scattered texts and group chats, they return naturally — which makes Relevé essential to the *studios* too. Every idea below should be evaluated against "does this make the family's week easier and pull them back to This Week?"

## Ideas (all tied to This Week / calendar entries)
1. **RSVP / attendance on events.** For events like rehearsals and competitions, let families indicate whether they'll attend. Studios see the count/list per event.
2. **Automated event reminders.** Send reminders for upcoming events that prompt families to check in or confirm attendance (nudge back into This Week).
3. **Message / note feature tied to calendar entries.** Let studios post last-minute changes or reminders *attached to a specific calendar entry* (e.g., "call time moved to 4:15" on that rehearsal), so the change lives where families already look.
4. **Read receipts on updates.** Let a studio see *who has viewed* an update/change — so they know a critical change actually reached families.
5. **Quick polls.** Lightweight polling for scheduling decisions (e.g., "which Saturday works for the extra rehearsal?").
6. **Occasional exclusive content.** Special studio news or offers available *only* through Relevé, reinforcing that it's the go-to hub (use sparingly so it stays special).

## Notes for whoever builds this
- These extend the **This Week** model already in the product; prefer building them as attributes/actions on existing calendar entries rather than a separate messaging silo.
- Respect the existing privacy model (family data stays private to the family; studio sees roster-level signals like RSVP counts and read status, not private family info beyond what's needed).
- Keep the family experience low-friction — the whole point is convenience.
- Do not start these until the current blocker fix + core This Week/roster flow are green and retested.
